# Student-Tutor Matching System

A web application that connects students with tutors based on their learning needs. The system allows students and tutors to manage their profiles, subjects, availability, bookings, and reviews.

## Built With

- Python
- Django
- JavaScript
- HTML5
- CSS3
- SQLite

## Features

- Student and tutor registration
- Role-based user accounts
- User authentication
- Student and tutor profiles
- Subject management
- Tutor availability management
- Tutor booking
- Reviews and ratings
- Database-driven application functionality
- Responsive web interface

The project follows Django's application structure, with the backend handling application logic, authentication, database operations, and routing, while the frontend uses HTML, CSS, and JavaScript for the user interface.

## Getting Started

### Prerequisites

Make sure you have Python installed on your computer.

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd TutorMatching
```

Create and activate a virtual environment:

```bash
python -m venv venv
```

On Windows:

```bash
venv\Scripts\activate
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the database migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open the application at:

```text
http://127.0.0.1:8000/
```
