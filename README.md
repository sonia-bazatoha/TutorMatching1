# Student-Tutor Matching System

A web application that connects students with tutors based on their learning needs. The system allows students and tutors to manage their profiles, subjects, availability, bookings, and reviews.

## Built With

- Python
- Django
- JavaScript
- HTML5
- CSS3
- SQLite

## Features

- Student and tutor registration
- Role-based user accounts
- User authentication
- Student and tutor profiles
- Subject management
- Tutor availability management
- Tutor booking
- Reviews and ratings
- Database-driven application functionality
- Responsive web interface

## Project Structure

The project follows Django's application structure, with the backend handling application logic, authentication, database operations, and routing, while the frontend uses HTML, CSS, and JavaScript for the user interface.

## Getting Started

### Prerequisites

Make sure you have Python and Pipenv installed on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/sonia-bazatoha/TutorMatching1.git
```

Move into the project directory:

```bash
cd TutorMatching1
```

Install the project dependencies:

```bash
pipenv install
```

Activate the virtual environment:

```bash
pipenv shell
```

Run the database migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open the application in your browser:

```text
http://127.0.0.1:8000/
```

### Database

The project currently uses SQLite for development.
